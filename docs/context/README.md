## 当前文档

| 文件 | 内容 |

## 维护原则

- **只放稳定知识**：参数、选型、来源等不会频繁变化的信息
- **标注信息来源**：每条数据标注提取自哪个文件 / 哪份文档
- **按需新增**：架构设计、数据链路等待稳定后再落入
